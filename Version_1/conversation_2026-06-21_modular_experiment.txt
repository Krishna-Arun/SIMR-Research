USER REQUEST
================================================================================

User wanted to create two different test conditions for the AKI benchmark:
1. WITH tools: Answering agent with access ONLY to the two MIMIC-IV lab tools
2. WITHOUT tools: Answering agent with zero external tools

Key requirements:
- Modular architecture (easy to swap models, add new conditions later)
- Detailed kidney specialist system prompts for both agents
- Both agents can only call the 2 lab MCP tools (NOT guidelines search, NOT PubMed)
- No hardcoding - everything should be configurable

================================================================================
ARCHITECTURE DECISIONS
================================================================================

The framework uses CONDITION_CONFIGS as the central "modularity seam":

    const CONDITION_CONFIGS = {
      with_lab_tools: { label, model, system_prompt },
      no_tools:       { label, model, system_prompt },
      // Future entries go here (GPT-4, Gemini, multi-agent, +PubMed)
    }

Adding a new condition = one new entry in this object. Zero other changes.

Tool restriction mechanism: Claude workflows cannot programmatically hide MCP tools,
so restriction is enforced entirely via system prompt instructions ("DO NOT call X").

   Args: { condition: string, case_id: number }
